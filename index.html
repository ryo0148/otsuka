第3章 典型金属元素とその化合物

アルカリ金属とその化合物

アルカリ金属

  • 原子は1価の陽イオンになりやすい。
  • 単体を得るには、化合物を溶融塩電解する。
  • 単体や化合物は、特有の炎色反応を示す。
  • 常温の水と反応して水素を発生し、水酸化物は強い塩基性を示す。
  • 反応性が高いため、石油中に保存する。

ナトリウムの化合物

水酸化ナトリウム NaOH：空気中の水分を吸収して溶ける（潮解）。

炭酸ナトリウム Na₂CO₃：別名ソーダ灰。十水和物が水和水を失い粉末状になる現象を風解という。工業的にはアンモニアソーダ法（ソルベー法）でつくられる。

ソルベー法の重要点：
主反応で溶解度の小さいNaHCO₃が沈殿する。
副生したNH₄ClにCa(OH)₂を反応させて、アンモニアを回収・再利用する。

炭酸水素ナトリウム NaHCO₃：重曹とも呼ばれ、水溶液は弱塩基性を示す。

アルカリ土類金属とその化合物

アルカリ土類金属

原子は2価の陽イオンになりやすい。Ca, Sr, Baは常温の水と反応して水素を発生する。

カルシウムの化合物

名称化学式特徴
酸化カルシウムCaO生石灰。乾燥剤などに利用。
水酸化カルシウムCa(OH)₂消石灰。飽和水溶液は石灰水。
炭酸カルシウムCaCO₃石灰岩・大理石・貝殻の主成分。
硫酸カルシウムCaSO₄二水和物はセッコウとして存在。

石灰水にCO₂を通すとCaCO₃の白濁が生じるが、さらに通すと水に溶けやすい炭酸水素カルシウム（Ca(HCO₃)₂）となる。

1, 2 族以外の典型金属元素とその化合物

アルミニウム

  • 3個の価電子をもち、酸化アルミニウムを溶融塩電解して製造する。
  • 濃硝酸とは不動態をつくり溶けない。
  • 酸にも強塩基にも反応して水素を出す両性金属である。

+ 過剰NaOH → [Al(OH)₄]⁻(無色溶液) / + 過剰NH₃ → 溶けない]

スズ・鉛

スズ：単体は両性金属。スズめっき鋼板はブリキと呼ばれる。

鉛：単体は両性金属。塩酸や希硫酸には表面に不溶性の塩をつくるため、ほとんど溶けない。

遷移元素とその化合物

鉄とその化合物

単体は濃硝酸には不動態となるため溶解しない。鉄・クロム・ニッケルの合金をステンレス鋼という。

鉄イオンの反応：
Fe²⁺ + NaOH → 緑白色沈殿 Fe(OH)₂
Fe³⁺ + NaOH → 赤褐色沈殿 FeO(OH)
Fe³⁺ + KSCN → 血赤色溶液
Fe²⁺ + K₃[Fe(CN)₆] → 濃青色沈殿（ターンブルブルー）

銅・銀・亜鉛

銅：湿った空気中で緑色のさび（緑青）を生じる。水溶液中でCuSは黒色沈殿となる。

銀：電気伝導性・熱伝導性が金属中で最大。水溶液中でAg₂Sは黒色沈殿となる。

亜鉛：両性金属。合金である黄銅（真鍮）や亜鉛めっき鋼板であるトタンに用いられる。ZnSは白色沈殿となる。
