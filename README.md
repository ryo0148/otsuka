# Memory Motor Poster Script Explained

GitHub Pages 用の最小構成です。

## 含まれるもの

- `index.html`
- `assets/en/sentence_001.wav` から `sentence_022.wav`

## 公開方法

1. この `memory_motor_poster_v6_flow_explained_public` フォルダの中身を GitHub リポジトリに置く
2. GitHub Pages を有効化する
3. 公開先を `main` ブランチの `/root` か、このフォルダをそのまま使うなら専用リポジトリにする

## 注意

- 音声は相対パス参照なので、`index.html` と `assets` の階層は変えないでください
- GitHub 上で公開するなら、ローカルの `shadowing_player_share` は不要です
